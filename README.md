# BUBOSOFT SHIELD Web App

Responsive React + Vite dashboard prototype for the BUBOSOFT SHIELD kapok processing and repellent production machine.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy to Vercel
Import this GitHub repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Important
This is a dashboard UI prototype with placeholder readings. It is not connected to Firebase or the Arduino Mega 2560, and the machine controls do not operate physical hardware. Connect hardware only after implementing and testing a safe communication layer.
